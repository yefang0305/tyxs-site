核心口诀 同我比劫，我生食伤，我克财星，克我官杀，生我印绶。
阴阳相同为"偏"，阴阳相异为"正"。
同我 → 比/劫 同五行同阴阳 = 比肩
同五行异阴阳 = 劫财
我生 → 食/伤 同阴阳 = 食神（福气）
异阴阳 = 伤官（锋芒）
我克 → 财 同阴阳 = 偏财（横财）
异阴阳 = 正财（正收入）
克我 → 官/杀 同阴阳 = 七杀（压力）
异阴阳 = 正官（规范）
生我 → 印 同阴阳 = 偏印（技艺）
异阴阳 = 正印（学业）

阴干：乙丁己辛癸
